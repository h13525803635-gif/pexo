核心结论

V2（silent_hearts_full_v2.mp4） 是 QA 所指的「修订后更差」的主要成片：去掉 seg15 并加 crossfade，但仍用 seg5/7/10 各播两遍 填补缺失段，且仅有视频轨、每段内嵌 co-generated 音频拼接。V3 在用户要求「无音乐、只要口型表情」后又批量重生 v3_seg1–10，积分耗尽，未交付 full_v3。

问题与解决方案

P1 — Revision made it worse
每次修订在错误时间线上叠补丁
V2 未解决缺段；V2 TTS/v2_lip 从未进成片；V3 全量 silent 重生且未交付。
  • 禁止用相邻段复制填洞（seg4→5, seg6/8→7, seg11→10）
  • 修订流程：先改 edit spec → 用户确认 → 再 render
  • 「去掉音乐」= assembly mute，不要默认 v3_seg* 全量重生
V1: 16 段硬拼（seg15 用 3 次）
V2: 删 seg15 + crossfade，仍重复 5/7/10
歌词修订: v2_lip 生成但未组装
V3: v3_seg 重生 → 积分耗尽
修复: 缺段补生成 + 单 master 音轨 + 最小 diff 修订
P1 — Audio issue
无双音轨策略 → 重复/错位/非原曲
  • trace-9: 段内 co-gen + 用户 MP3 叠加（AUDIO DUPLICADO）
  • trace-11: 画面比音乐慢
  • V2: 无 audio_tracks，仅段内嵌音频
  • Lipsync 默认 sound=off；master = 用户 MP3 或 TTS
P1 — Bad pacing
固定 15s 网格 + 重复镜头
  • 应按歌词时间轴切分，非 uniform 15s
  • 全曲 segment 齐再组装；缺段缩短或占位，禁止 duplicate
  • 支持 per-clip speed 对齐音乐节拍
