问题与解决办法

P0 — Hook 金句消失
原因：VO 被摘要改写，未 beat-locked
修复：VO 首句用用户原文；skill 加时间码检测
P0 — 4 拍变 3 段
原因：为省段数合并 Twist+Climax
修复：4 段 5+8+10+7s；禁止合并用户时间码
P0 — 无避难所镜头
原因：seq1/2 未分配 shelter beat
修复：Twist 段专拍掩体/收容
P1 — 音画不同步
原因：非 VO-First，无 trim
修复：先 VO 再视频；trim 至 30.0s
P1 — 音轨打架
原因：sound:on + 独立 VO
修复：sound:off；视频轨 vol=0
P1 — reference2video 无图
原因：误用 mode，无 image_list
修复：纯文生用 text2video
P1 — 人脸不一致
原因：跳过 subject-asset
修复：主角设定图 + 各段 ref
P2 — 仅 720p
原因：未锁分辨率
修复：creative lock + 短 prompt
