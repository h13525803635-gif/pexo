核心结论

Wrong visual style 根因： 用户「ok」仅确认 16:9 / 10–15s，Agent 却将 dark navy + gold D + flat plane icon 当作已确认风格；且 已验收 PNG 未进成片，编辑器重排为 U B A I 空格字 + 贴纸飞机，破坏 typographic pun。

问题与解决办法

P0 — 风格未经确认
原因：Format「ok」被当成 Style 确认
办法：Style Gate 独立；交付前 1 张 mood / 沿用已批 keyframe
P0 — Keyframe 未进成片
原因：先 image_generate 后改 editor text
办法：PNG 为唯一视觉标准，或不要生成 PNG
P0 — 字谜编排错误
原因：edit_spec 拆 3 个 text track
办法：整词 Ubaid + D 子串 anim；禁 U B A I
P0 — 飞机非穿字
原因：plane_icon flat + overlay
办法：mask/matte 与字同层合成

推荐重做产线

  1. 澄清动效 + 确认视觉风格（与 Format 分开）
  2. script-skill：Beat1 整句 → Beat2 D 前移 → Beat3 飞机穿字（同 compositing）
  3. 生产二选一：A) 已批 PNG 为底 + anim D/plane；B) 纯 editor 但对齐 script
  4. 禁止 flat icon 横扫；禁止两套 typography
  5. show_final_video
